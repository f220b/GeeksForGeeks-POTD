## 📁 Repository Structure

Problems are grouped by difficulty, matching GeeksforGeeks' own classification:

```
GeeksForGeeks-POTD/
├── Difficulty: Basic/
├── Difficulty: Easy/
├── Difficulty: Medium/
├── Difficulty: Hard/
└── README.md
```

Each solution file is named after the problem it solves and contains a working, tested implementation.
